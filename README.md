# Simulasi-Vending-Machine
Pada mini project ini, diterapkan beberapa konsep dasar pemrograman, yaitu percabangan, perulangan, fungsi, input dan output, serta array. Konsep-konsep tersebut diterapkan dalam sebuah program yang mensimulasikan cara kerja vending machine.
Vending machine dipilih sebagai ide mini project karena mekanisme kerjanya dapat disimulasikan menggunakan kode program serta sesuai dengan materi yang telah dipelajari. Dengan demikian, project ini dapat digunakan untuk menerapkan konsep-konsep tersebut dalam suatu program yang memiliki alur kerja yang jelas.

Dalam program ini, input diimplementasikan dengan user menginput baris dan kolom dari barang yang dipilih dan uang yang akan dibayar oleh user, dan output diimplementasikan dengan keluaran barang yang dipilih serta kembalian yang dikeluarkan. Percabangan diimplementasikan dengan pilihan user untuk melanjutkan membeli barang atau tidak. Perulangan diimplementasikan dengan fitur membeli kembali barang dalam vending machine. Array diimplementasikan untuk tampilan dari vending machine dan menunjukkan posisi dari barang. Fungsi digunakan untuk menampilkan tampilan dari vending machine.
